## 🛠️ Topics & Implementations

### 🔹 Stack
- Stack class with `push`, `pop`, `peek`, `is_empty`, `size`
- **Balanced Parenthesis Checker** — validates expressions like `{[()]}` using stack logic
- Bracket matching with detailed step-by-step tracing

### 🔹 Queue
- Queue using Python List (`append` / `pop(0)`)
- Queue using `collections.deque` (optimized `popleft`)
- Queue using `queue.Queue` (thread-safe, with `maxsize`)
- **Custom Queue Class** — `enqueue`, `dequeue`, `front`, `rear`, `display`
- **Queue using Linked List** — Node-based implementation with dynamic memory

### 🔹 Tree & Graph Traversals
- **Binary Tree** — Insert, Inorder, Preorder, Postorder traversal
- **DFS (Depth-First Search)** — Recursive graph traversal with visited set
- **BFS (Breadth-First Search)** — Level-order graph traversal using `deque`
- Tested on custom adjacency list graphs

### 🔹 Deep Learning — Perceptron
- **Perceptron from scratch** using only NumPy (no frameworks)
- Training with learning rate and iterative weight updates
- **Decision Boundary Visualization** with Matplotlib & Seaborn
- Accuracy evaluation on synthetic classification dataset (`sklearn.make_classification`)
